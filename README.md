### 🧑‍💻 Sobre mim

Sou **Victor Hugo Sinhoreli Gomes**, Engenheiro de Computação formado pela **UNILAGO** (São José do Rio Preto, SP).
Desenvolvo aplicações web full stack com **Python, Django, React e Next.js**, pensando em software de produção, não em protótipo.

Venho da área de **infraestrutura e suporte de TI** (Active Directory, Microsoft 365, VPN, redes) e hoje atuo como **Analista de Suporte N2**.
Também já entreguei, como freelancer, um pipeline de **CI/CD** com Docker, Azure, Artifactory e Bitbucket para clientes no Brasil e no exterior.
